1. **Removed Capacitor entirely** (root `android/`, `capacitor.config.ts`, `@capacitor/*` deps).

## 4. Problems encountered and how they were solved

### 4.1 Two Android projects fighting each other

- **Issue:** Root `android/` (Capacitor) and `mobile/android/` (Expo) both used `com.ctrend.app`; two Gradle trees consumed RAM.
- **Fix:** Deleted root `android/` and Capacitor deps. Mobile-only path.

### 4.2 PC / Linux OOM (Chromium killed)

- **Symptoms:** `app-org.chromium.Chromium-….scope terminated … low on memory`; builds interrupted.
- **Cause:** 13 GB RAM, **512 MB swap full**, multiple Gradle daemons, Cursor/Java, Chrome.
- **Fixes:**
  - Swap increased to **8 GB**: `sudo ./scripts/increase-swap-8g.sh`
  - Gradle memory capped in `mobile/android/gradle.properties`: `org.gradle.jvmargs=-Xmx1024m`, `org.gradle.daemon=false`, `org.gradle.workers.max=2`
  - Safe build script: `scripts/build-mobile-apk-safe.sh` (sets `TMPDIR=$HOME/tmp`, stops daemons)
  - Close extra browser tabs; **close Android Studio** during CLI builds

### 4.3 `/tmp` full (build failures)

- **Symptoms:** `No space left on device`, npm `ENOSPC`, Gradle cache errors under `/tmp/cursor-sandbox-cache/`.
- **Cause:** tmpfs `/tmp` ~6.8 GB 100% full from Cursor sandbox cache.
- **Fix:** `rm -rf /tmp/cursor-sandbox-cache/*` and always build with:
  ```bash
  export TMPDIR=$HOME/tmp
  export GRADLE_USER_HOME=$HOME/.gradle
  export NPM_CONFIG_CACHE=$HOME/.npm
  ```

### 4.4 `react-native-worklets` version hell

- **Issue:** Monorepo hoisted conflicting worklets versions (`0.8.3` in `mobile/node_modules` vs `0.9.1` for Reanimated 4.4).
- **Symptoms:** Gradle C++ errors: `Expected 0.9.0, but got 0.8.0`; missing `libworklets.so`.
- **Fixes:**
  - Root `package.json` override: `"react-native-worklets": "0.9.1"`
  - `mobile/package.json` direct dep: `"react-native-worklets": "0.9.1"`
  - Symlink when npm nests wrong copy:
    ```bash
    rm -rf mobile/node_modules/react-native-worklets
    ln -sf ../../node_modules/react-native-worklets mobile/node_modules/react-native-worklets
    ```

### 4.5 Debug APK tried to load JS from Metro on phone

- **Symptoms:** App opens blank / hangs; logcat: `Couldn't connect to ws://localhost:8081/...`
- **Cause:** Default RN debug builds skip bundling JS (`debuggableVariants = ["debug"]` implicitly).
- **Fix:** In `mobile/android/app/build.gradle` inside `react { }`:
  ```gradle
  debuggableVariants = []
  ```
  Forces `export:embed` bundle inside APK. **Note:** `expo prebuild` may reset comments but this line was kept manually — re-verify after prebuild.

### 4.6 “Page not found” on launch

- **Cause:** No `mobile/app/index.tsx` for route `/`.
- **Fix:** Added `mobile/app/index.tsx` → redirect to `/auth/login` or `/tabs` based on auth. Updated `+not-found.tsx` link to `/tabs`.

### 4.7 App not visible in launcher

- **Cause:** Package installed but **`enabled=0`** (disabled).
- **Fix:** `adb shell pm enable com.ctrend.app`

### 4.8 Install signature mismatch

- **Symptoms:** `INSTALL_FAILED_UPDATE_INCOMPATIBLE: signatures do not match`
- **Fix:** `adb uninstall com.ctrend.app` then fresh install.

### 4.9 Native crash on open (`valueUnpacker not found`)

- **Symptoms:** App instant crash; logcat:
  ```
  react-native-worklets/.../Serializable.cpp:21: valueUnpacker not found
  ```
- **Cause:** `expo-router` pulls **Reanimated 4** → **worklets**; Babel plugin was missing from bundle.
- **Fix:** Added to `mobile/babel.config.js` (must be **last** plugin):
  ```js
  plugins: [
    ["module-resolver", { alias: { "@ctrend/shared": "../packages/shared/src" } }],
    "react-native-reanimated/plugin",  // includes worklets plugin; do NOT add worklets/plugin twice
  ]
  ```
- **Verified:** `npx expo export:embed --platform android` bundles successfully after this change.
- **Important:** Do **not** add both `react-native-worklets/plugin` and `react-native-reanimated/plugin` — duplicate plugins break Metro (`transformFile` undefined).

### 4.10 Google Sign-In missing on mobile login

- **Cause:** Mobile login only had email/password; web uses `@react-oauth/google`.
- **Fix:**
  - Installed `@react-native-google-signin/google-signin`
  - `mobile/lib/googleAuth.ts`, `mobile/components/GoogleSignInButton.tsx`
  - Wired into `mobile/app/auth/login.tsx` and `signup.tsx`
  - `mobile/.env`: `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID=...` (same web client ID as `.env.production`)
  - `mobile/app.json` plugin with `iosUrlScheme`

### 4.11 Google Sign-In still needs Google Cloud Console (Android OAuth client)

- **Not done in session:** User must create **Android** OAuth client in Google Cloud:
  - Package: `com.ctrend.app`
  - Debug SHA-1: `3A:88:C4:FD:BF:5E:48:F0:10:84:1F:BD:F3:93:01:9B:D4:57:FE:B6`
  - Web client ID stays in `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID`
- Without Android client → `DEVELOPER_ERROR` or sign-in failure on device.

## 7. Commands that work

### One-time / maintenance

```bash
# Swap (needs sudo password once)
sudo ./scripts/increase-swap-8g.sh

# Clear full /tmp if builds fail with ENOSPC
rm -rf /tmp/cursor-sandbox-cache/*

# Fix worklets symlink if Gradle can't find libworklets.so
rm -rf mobile/node_modules/react-native-worklets
ln -sf ../../node_modules/react-native-worklets mobile/node_modules/react-native-worklets
```

### Build & install (recommended)

```bash
export TMPDIR=$HOME/tmp
export GRADLE_USER_HOME=$HOME/.gradle
export ANDROID_SERIAL=YOUR_DEVICE_ID   # optional

./scripts/build-mobile-apk-safe.sh
```

APK output: `mobile/android/app/build/outputs/apk/debug/app-debug.apk` (~200+ MB)

Manual install:

```bash
adb uninstall com.ctrend.app          # if signature conflict
adb install -r mobile/android/app/build/outputs/apk/debug/app-debug.apk
adb shell pm enable com.ctrend.app
adb shell am start -n com.ctrend.app/.MainActivity
```

### Verify bundle before Gradle (after JS changes)

```bash
cd mobile
export TMPDIR=$HOME/tmp
npx expo export:embed --eager --platform android --dev false
```

### Debug logcat

```bash
adb logcat -c
adb shell am start -n com.ctrend.app/.MainActivity
sleep 5
adb logcat -d | grep -iE "FATAL|ReactNativeJS|valueUnpacker|8081|ctrend"
```

## 12. Known pitfalls (do not repeat)

1. Building **both** Capacitor and Expo Android projects on a 13 GB machine.
2. Running Gradle without `TMPDIR=$HOME/tmp` when `/tmp` is full.
3. Using `CI=1` with `expo run:android` (non-interactive device selection fails).
4. Adding **both** worklets and reanimated Babel plugins.
5. Forcing worklets `0.8.x` when Reanimated 4.4 needs `0.9.x`.
6. Forgetting `adb uninstall` when switching Capacitor ↔ Expo APK (same package id).
7. Forgetting `adb shell pm enable` when app installed but disabled.
